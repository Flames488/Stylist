# Fica Braids website

A responsive single-page HTML/CSS/JavaScript website using the supplied braid photos.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Deploy
Upload the complete `fica_braids_site` folder to a static host such as Netlify, Cloudflare Pages, GitHub Pages, or any standard web host.

## Replace before launch
1. The supplied Fica Braids logo is included at `assets/fica-logo.png`.
2. Replace `SITE_CONFIG.bookingUrl` in `index.html` with the real Acuity booking URL.
3. Replace Instagram `HANDLE` and its profile URL with the real handle.
4. Confirm whether the demo +234 phone number is appropriate for the Toronto business; replace it if needed.
5. Confirm the “From $20” price placeholder for every service.
6. Replace the placeholder reviews with genuine client testimonials or remove the reviews section.
7. The map currently embeds Downtown Toronto as a general area because the exact home-salon address is private and has not been provided. Update the map query only if the owner wants a precise location shown.
7. Replace image placeholders with approved client photos where possible.
8. Confirm the hair-supply and lateness policies.
9. Add the actual salon address only if the owner wants it public; current copy says it is shared after booking.
10. Replace the generic map placeholder with a real map or directions link if appropriate.

## Notes
- The page uses Google Fonts when online, with system font fallbacks.
- The supplied customer photos are used locally from the `assets/` directory; they are not hotlinked.
- Service prices are marked as placeholders. Update the `From $20` labels in the service cards once prices are confirmed.
